# Mensagens e follow-ups — modelo

Cole somente textos aprovados para a nova empresa. Use `{ClientName}` como marcador; o código o substitui quando a lead fornecer nome.

## Primeira resposta

Para cada serviço, defina:

- Saudação e abertura.
- Dados da casa que devem ser repetidos.
- Como preço ou duração serão apresentados.
- Perguntas obrigatórias.
- Ressalvas de serviços adicionais.
- Assinatura, site e telefone.

## Dados faltantes

Defina a mensagem usada quando não houver tamanho suficiente para cotar. Informe exatamente quais dados pedir: metragem, quartos/banheiros, fotos, vídeo ou outro.

## Sem vaga compatível

Confirme se deve pedir dia preferido, manhã/tarde, endereço e telefone. A mensagem não deve afirmar indisponibilidade interna ao cliente, a menos que essa seja uma regra comercial explícita.

## Follow-ups independentes

Cada modelo é escolhido pela pessoa operadora conforme a situação; não há uma sequência obrigatória. Para cada item, forneça:

| Modelo | Situação de uso | Texto completo | Frase única para detectar no chat |
| --- | --- | --- | --- |
| Follow-up 1 |  |  |  |
| Follow-up 2 |  |  |  |
| Follow-up 3 |  |  |  |
| Follow-up 4 |  |  |  |

A frase de reconhecimento deve ser estável e suficientemente específica para não coincidir com uma mensagem comum do cliente. O botão correspondente apenas copia o texto e fica bloqueado se essa frase já estiver visível no chat do Yelp.
